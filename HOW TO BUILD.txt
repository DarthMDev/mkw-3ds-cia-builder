MARIO KART WII FOR 3DS: BUILD YOUR CIA
======================================

This folder holds no game files. It builds the CIA from your own disc, on
your own computer.


WHAT YOU NEED
-------------
- Your Mario Kart Wii disc, USA version (RMCE01), dumped as .iso or .wbfs.
  RVZ or NKit dumps: convert them to ISO in Dolphin first.
- A computer with about 15 GB free and an internet connection.
- These free tools, installed once:
    Python 3.11 or newer       https://www.python.org/downloads/
    Node.js (LTS)              https://nodejs.org
    Git                         https://git-scm.com/downloads
    devkitPro with 3DS tools    https://devkitpro.org/wiki/Getting_Started
- On Windows, install the Windows devkitPro environment and the 3DS
  development tools. The Windows launcher can automatically detect
  C:\Users\<you>\Downloads\cia\devkitPro, or you can set DEVKITPRO
  to your devkitPro installation folder.


BUILD
-----
1. On macOS, double-click "Build MKW CIA.command". If macOS blocks it,
   use System Settings > Privacy & Security > Open Anyway.
   On Windows, double-click "Build MKW CIA.bat".
2. Drag your disc image into the terminal/console window (or paste its full
   path), then press Return/Enter.
3. Wait; the build can take a long time. Your CIA is saved here:
       build/release/mkw-3ds.cia

If it stops partway, run the launcher again; finished steps are skipped.
If it fails, share build-cia-log.txt from this folder when asking for help.
On Windows, if the build reports a missing DEVKITPRO or toolchain component,
finish the devkitPro setup before running the launcher again.


INSTALL
-------
Needs a 3DS with custom firmware (https://3ds.hacks.guide).
1. Copy mkw-3ds.cia to your SD card.
2. Install it with FBI. Mario Kart Wii appears on the HOME Menu.
3. For sound, run DSP1 once to dump your sound firmware.

Old 3DS and 2DS run at 30 FPS. New 3DS and New 2DS run at 60 FPS
(30 FPS with the 3D slider up).
